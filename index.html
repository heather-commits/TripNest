TripNest

TripNest is an Android travel planning application designed to help users organize vacations, excursions, notes, alerts, and trip information in one convenient location.

Features

  • Vacation and excursion management
  • Vacation notes
  • Global search across travel information
  • Travel summary reports
  • Vacation and excursion notifications
  • PIN-based access protection
  • Local Room database persistence

Installation

Download the APK to an Android device. If prompted, allow installation from the browser or file manager being used to open the APK. Once installation completes, launch TripNest from the device application list.

Because TripNest is distributed outside the Google Play Store for this capstone deployment, Android may display a warning before allowing the APK to be installed.
